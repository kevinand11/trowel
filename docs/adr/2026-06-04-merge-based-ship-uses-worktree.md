# Host-owned local merges use worktrees

Host-owned local merges run inside trowel-managed **Worktrees**, rather than checking out merge targets in the user's main working tree. Merge-based **Ship** performs the local Target-branch merge inside the reserved `__merge-change` Worktree under the Change's worktree root; that Worktree checks out a detached HEAD at the Target branch tip, merges the Integration branch, and pushes `HEAD` to the Target branch. Slice-branch host merges likewise avoid the main checkout by using the reserved `__merge-slice` Worktree under the Change's worktree root, checking out a detached HEAD at the Integration branch tip before merging the Slice branch and pushing `HEAD` to the Integration branch. Host-owned merge commands may reset and reuse an existing reserved merge Worktree after printing a clear warning; the reset must clear both worktree contents and any in-progress merge state before starting a new merge. Successful slice Integration-merge Worktrees are kept for reuse until Change-level Cleanup removes the Change's trowel-managed Worktrees. Ship and Abort refuse when the user's current branch is a local branch Cleanup may delete; the user must switch branches first, so terminal commands do not switch the main checkout as part of Cleanup. Successful Ship leaves the ship Worktree for the normal Cleanup pass, while a failed merge preserves it and reports its path for inspection; a later retry may reset and reuse it.

## Considered Options

- **Use the user's main working tree.** Rejected because host-owned local merges would disturb the user's current branch even though they can happen safely in separate Worktrees.
- **Use an OS temp directory.** Rejected because trowel-managed Worktrees already have Cleanup ownership and predictable inspection paths.
- **Always refuse when a reserved merge Worktree exists.** Rejected because successful slice host merges would either block later slices or require immediate removal; resetting and reusing reserved merge Worktrees keeps the retry path simple while preserving the original Slice or Integration branch commits.
